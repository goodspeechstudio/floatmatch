# Float Match

Match each star to their float in the 100th Macy's Thanksgiving Day Parade. Live at https://floatmatch.goodspeech.studio

- Static site served by GitHub Pages (`index.html`, `app.js`, `config.js`).
- Data lives in the Supabase project `floatmatch` (Host City org). `setup.sql` is the schema, functions and seed data.
- Host tools: open `/#host` and enter the host PIN (stored in the `host_secret` table).
